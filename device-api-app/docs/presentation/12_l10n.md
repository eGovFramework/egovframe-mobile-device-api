# 국제화 (l10n)

화면 문구와 도메인 오류 문구는 `lib/l10n`에 둔다. 위젯에 한국어 문장을 직접 쓰지 않는다.  
기능 설명 화면의 짧은 규칙은 [Flutter 활용 보완](./11_flutter_practices.md) 4절이고, 이 문서는 키를 추가하고 화면에 연결하는 절차다.

## 1. 파일

| 파일 | 역할 |
|------|------|
| `l10n.yaml` | 생성 설정. 기준 arb는 `app_ko.arb`, 출력 클래스는 `AppLocalizations` |
| `lib/l10n/app_ko.arb` | 한국어 원문. 플레이스홀더 메타(`@키`)도 여기 |
| `lib/l10n/app_en.arb` | 같은 키의 영어 |
| `lib/l10n/app_localizations*.dart` | `flutter gen-l10n` 생성물. 손수 수정하지 않음 |
| `lib/l10n/message_keys/{feature}_message_keys.dart` | UseCase·Repository가 반환하는 오류 키 상수 |
| `lib/l10n/app_message_resolver.dart` | 그 키를 `AppLocalizations` 메서드로 바꿈 |

`pubspec.yaml`의 `flutter: generate: true`가 생성을 켠다. `main.dart`는 `locale`을 `ko`로 고정하고, `supportedLocales`에 `ko`와 `en`을 둔다. 델리게이트는 `AppLocalizations.delegate`와 Material·Widgets·Cupertino 델리게이트다.

## 2. 문자열이 가는 두 경로

**화면이 직접 읽는 문구**는 arb 키만 있으면 된다. 위젯이 `AppLocalizations.of(context)!`로 getter를 호출한다.

```dart
final l10n = AppLocalizations.of(context)!;
Text(l10n.aiChatAiServerDisconnected);
```

AI 서버 미연결 안내가 이 경로다. 키는 `aiChatAiServerDisconnected`이고, `AiChatAiServerBanner`만 읽는다. 도메인 메시지 키는 없다.

**UseCase가 실패 원인만 돌려주는 문구**는 메시지 키를 거친다. 도메인은 `BuildContext`가 없으므로 arb 문장을 만들지 않고 키 문자열을 반환한다. 화면은 `resolveAppMessage(l10n, message)`로 문장을 만든다.

```text
FaceMeshMessageKeys.noFacesDetected  (= 'faceMeshNoFacesDetected')
  → resolveAppMessage
    → l10n.faceMeshNoFacesDetected
```

인자가 있는 오류는 키 뒤에 `|`와 값을 붙인다.

```text
faceMeshPickError|{예외 내용}
  → l10n.faceMeshPickError(error)
```

접두 상수는 `FaceMeshMessageKeys.pickErrorPrefix` (`faceMeshPickError|`)이다.

## 3. 키 이름

기능 접두사 + 역할이다. 얼굴 메시는 `faceMesh`, AI 채팅은 `aiChat`이다.

| arb 키 | 생성 getter |
|--------|-------------|
| `faceMeshTitle` | `l10n.faceMeshTitle` |
| `faceMeshSelectedCount` | `l10n.faceMeshSelectedCount(count)` |
| `aiChatAiServerDisconnected` | `l10n.aiChatAiServerDisconnected` |

얼굴 메시 문구는 `faceMesh`로 시작한다. 예전에 쓰던 `faceDetection` 접두사는 arb와 메시지 키에서 제거했다.

## 4. 키를 추가하는 순서

1. `app_ko.arb`와 `app_en.arb`에 **같은 키**를 넣는다. 한국어만 있으면 생성이 영어 로케일에서 그 키를 빠뜨린다.
2. `{count}` 같은 칸이 있으면 한국어 arb에 `@키` 메타를 둔다.

```json
"faceMeshSelectedCount": "{count}개 선택됨",
"@faceMeshSelectedCount": {
  "placeholders": {
    "count": { "type": "int" }
  }
}
```

영어 arb에는 문장만 두고, `@` 메타는 기준 파일인 한국어 arb에 둔다.

3. 생성한다.

```bash
flutter gen-l10n
```

4. 화면 문구면 위젯에서 `l10n.키`를 읽는다.
5. 도메인 오류면 `message_keys` 상수와 `app_message_resolver.dart` 분기를 같이 추가한다. 상수 값과 arb 키 문자열을 맞춘다.

## 5. 얼굴 메시

| 위치 | 내용 |
|------|------|
| `app_ko.arb` / `app_en.arb` | `faceMesh*` 화면 문구. 안내, 버튼, 빈 목록, 삭제 확인 |
| `face_mesh_message_keys.dart` | 권한, 얼굴 없음, 업로드 실패, `*ErrorPrefix` |
| `app_message_resolver.dart` | `FaceMeshMessageKeys` → `l10n.faceMesh*` |
| 기능 설명 | `l10n.faceMeshTitle`, `l10n.faceMeshGuideOverview` |

조사는 키를 바꿀 때 문장 전체를 다시 읽는다. “얼굴 메시” 뒤에는 “를”이 온다 (`얼굴 메시를 검출할 이미지를 선택하세요`).

## 6. AI 채팅 미연결 안내

| 항목 | 값 |
|------|-----|
| arb 키 | `aiChatAiServerDisconnected` |
| 한국어 | AI 서버에 연결되어 있지 않습니다. 저장된 대화는 볼 수 있지만 새 질문은 보낼 수 없습니다. |
| 위젯 | `AiChatAiServerBanner` |
| 표시 조건 | Riverpod `aiServerConnected == false`. 절차는 [Riverpod 화면 상태](../architecture/8_riverpod.md) |

이 문장은 서버가 내려주는 오류 키가 아니다. 앱이 연결 결과를 해석한 뒤 고정 문구를 보여 준다.

## 7. 체크리스트

- [ ] `app_ko.arb`와 `app_en.arb`에 같은 키를 넣었는가
- [ ] `{이름}`이 있으면 한국어 arb에 `@키.placeholders`가 있는가
- [ ] `flutter gen-l10n` 이후 getter 이름으로 위젯이 컴파일되는가
- [ ] 도메인 오류라면 message key·resolver·arb가 한 세트인가
- [ ] 위젯 소스에 사용자에게 보이는 한국어 문장을 새로 넣지 않았는가
